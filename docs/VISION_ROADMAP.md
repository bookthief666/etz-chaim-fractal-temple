# Vision Roadmap — Etz Chaim Fractal Temple

## North star

The project is not a collection of occult-themed shader presets. It is a recursive contemplative instrument in which:

- the Tree is a navigable mathematical cosmogram;
- every Sephirah has its own visual/mathematical law;
- descent changes that law through explicit recursive rites;
- the paths transform one law into another rather than acting as menu lines;
- documentary correspondences can be studied without being confused with our visual interpretation;
- eventually the same mathematical state can drive sound, XR space, ritual text, and deeper Tree-within-Tree recursion.

## Five axes that must advance together

### 1. Structural fidelity

The selected Tree topology remains explicit, testable and independent from correspondence systems.

### 2. Esoteric/source fidelity

Jewish Kabbalah, Christian Cabala, Golden Dawn Hermetic Qabalah, Crowley/777, and our own visual synthesis must remain distinguishable. Historical disagreement should be representable rather than silently harmonized.

### 3. Mathematical identity

A Sephirah is not a color preset. Its geometry, distance field, symmetry, repetition, temporal law, motion and light behavior must be meaningfully different.

### 4. Transformative traversal

A path should change the user's mathematical world continuously. Destination changes should be experienced, not hidden behind a fade.

### 5. Contemplative usability

The interface should remain quiet enough to support attention. Study, ritual and pure-vision modes can reveal different layers without turning the Tree into a dashboard.

## Acceptance gates before scaling paths

Do not implement all twenty-two operative path shaders until:

1. Kether survives repeated Fold entry/exit without renderer failure.
2. Geburah↔Tiphareth reads clearly at start, midpoint and destination in both directions.
3. Yesod↔Malkuth reads clearly in both directions.
4. path abort and destination handoff are reliable.
5. Fold frame pacing remains acceptable.

## Design rule

Every major addition should improve at least three of:

- legibility;
- recursion;
- symbolic coherence;
- mathematical distinctness;
- transformation;
- contemplative depth;
- physical-device reliability.

Spectacle alone is not sufficient, and documentary correctness alone is not sufficient. The project succeeds when the mathematics, symbolism, interaction and atmosphere reinforce each other.
