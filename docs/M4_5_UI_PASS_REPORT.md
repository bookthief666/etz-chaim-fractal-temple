# M4.5 Pass Report — Living Grimoire Family UI

## Purpose

M4.5 deliberately pauses the planned M5 procedural-sonification work and upgrades the product shell so the Fractal Temple reads as part of the same application family as **Monas Hieroglyphica** and **Liber 333**, without copying either project wholesale or touching the accepted M4 mathematical/documentary architecture.

## Reference language carried forward

From the accepted Monas direction:

- near-black ceremonial stages;
- blackletter / medieval / Fell-style manuscript hierarchy;
- living central sigil rather than static branding;
- vignette, grain, shimmer, slow breathing motion and engraved geometry;
- registers of use rather than generic dashboard tabs;
- slow symbolic motion, not constant high-frequency animation.

From Liber 333:

- astral void palette with crimson, old gold and luminous silver;
- Cinzel / decorative inscription hierarchy with mono technical annotations;
- subtle rotating glyph fields and drifting marginalia;
- an interactive living-orb sensibility: the interface should feel dormant, awaken on contact, and then settle;
- Fold-aware safe-area composition and reduced-motion respect.

## New main page

The app now opens on a ceremonial threshold rather than immediately exposing the Tree as a utility diagram.

The threshold includes:

- animated **ETZ CHAIM** blackletter title;
- a procedural living Tree seal derived from the actual 10-node / 22-edge topology;
- concentric engraved orbits;
- animated path dashes and breathing Sephirah points;
- an original invocation line;
- deliberate `Initiate the Living Tree` entry action;
- visual register markers for VISIO / STUDIUM / CONTEMPLATIO;
- the real R3F Tree dimmed and breathing behind the threshold rather than a raster hero image.

No image texture was added to the cosmological UI.

## Whole-app UI covenant

The prior generic glassmorphism was replaced with a shared family grammar:

- obsidian / wine-black vellum;
- parchment, old-gold, crimson and Sephirah-reactive highlights;
- Cinzel Decorative for monumental headings;
- Cinzel for ritual controls;
- IM Fell English for reading / contemplation;
- JetBrains Mono for documentary and instrument annotations;
- UnifrakturCook reserved for the threshold identity;
- hairline engraved rules instead of generic card borders;
- squared grimoire controls instead of modern pill UI;
- source/study panels rethemed as illuminated dark folios.

The UI accent reads the existing visual grammar but never mutates topology, historical attribution, or shader authority.

## Living atmosphere

A deterministic CSS atmosphere now persists across Tree, realm and path phases:

- procedural grain;
- vignette;
- slow spectral shimmer;
- Sephirah-reactive aurora;
- enormous faint engraved rings;
- deterministic floating planetary / geometric marginalia.

Reduced-motion mode disables the ornamental motion while preserving the composition.

## Tree presentation refinement

Each Sephirah now carries:

- two differently oriented orbit systems;
- a small luminous satellite point;
- a restrained third ring when focused;
- preserved core/halo interaction and Fold hit behavior.

Paths now use parchment/gold family neutrals and inherit the focused Sephirah accent when an operative path becomes active.

## Return seal

The intrusive bullseye-like return mark was redesigned as a much smaller old-gold / crimson occult seal with an octahedral center, while the invisible target remains large enough for Fold and XR use.
