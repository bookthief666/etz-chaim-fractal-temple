# M1 Living Tree + Three Realm Prototypes

## Scope

This pass deliberately combines the minimum thematic architecture needed for serious future work with an immediately visible experiential upgrade.

### Interaction

The macro Tree now uses a two-stage interaction:

1. focus a Sephirah
2. inspect its folio and choose to enter

Returning from a realm restores focus to the same Sephirah, preserving contemplative continuity.

### Living Tree

Paths now breathe, carry deterministic travelling motes, and emphasize the local network connected to the currently focused Sephirah.

### Thematic data

The graph remains attribution-free. A separate Hermetic reception module carries the current 10-Sephirah Divine Name / Archangel / angelic-order / planetary-sphere set. The interface explicitly distinguishes this from the topology and marks source locking as provisional.

Known textual disagreement in Crowley's Hermetic material around the final two angelic orders is surfaced rather than erased.

### Realm grammar

Three dedicated shader kernels now prove that realm differentiation is mathematical rather than palette-only:

- Kether: high symmetry, centered source, sparse recursive pearls
- Binah: recursively subtracted cubical enclosure and negative-space chambers
- Yesod: mirrored smooth-union bodies with phase distortion and reflective/lensing response

All other Sephiroth retain the M0 fold-space kernel intentionally until their own mathematical grammar is implemented.
